## Hi, I'm Emin

I build small, practical systems tools — mostly Python, running on Arch Linux.
I like quiet utilities that do one thing well: backups, config sync, log watching,
network checks.

### What's in here

- **cryptmount** — LUKS container mount manager with keyfile support
- **firezone** — nftables/iptables rule manager with atomic apply and rollback
- **sysbackup** — Btrfs/ZFS-aware incremental backups with retention policies
- **paclone** — replicate an Arch system's package state in one command
- **journald-alert** — pattern-aware journald monitor with webhook alerts
- **opensword-browser** — experimental browser shell built on Qt

Most of these started as scripts I needed on my own machines and grew into
something worth keeping around.

### Languages

Python mostly, some shell.
